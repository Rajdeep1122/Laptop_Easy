# Laptop_Easy
This is a Django-powered web platform for college students to buy and sell used laptops directly from their peers on campus.


💻 LaptopEasy - College Laptop Resale Platform
LaptopEasy is a full-stack web application built with Django that provides a dedicated platform for college students to buy and sell used laptops directly from their peers on campus. It simplifies the process for final-year students to find buyers and for junior students to find affordable, reliable devices.

✨ Key Features
Product Listing for Sellers: Final-year students can easily create listings for their used laptops, including specifications, price, images, and contact information.

Browse and View for Buyers: Junior students can browse all available laptops on a clean, card-based interface and view detailed information for each listing.

Direct Buyer-Seller Contact: An integrated mailto: link allows interested buyers to contact sellers directly via email with a pre-filled subject line, ensuring seamless communication.

Admin Approval System: To maintain quality and prevent spam, every new listing must be reviewed and approved by an administrator through the Django admin panel before it becomes visible to the public.

🛠️ Tech Stack
Backend: Python, Django

Frontend: HTML, CSS, Bootstrap 5

Database: SQLite (default, easily switchable to PostgreSQL)

Image Handling: Pillow
